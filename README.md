# Sakura Pomodoro 🌸

ตัวจับเวลา Pomodoro ฉากถนนญี่ปุ่นยามเย็นแบบพิกเซลอาร์ต ภาพและเสียงทั้งหมดสร้างด้วยโค้ด
ติดตั้งเป็นแอปบนมือถือได้ (PWA) และใช้งานได้แบบออฟไลน์

## 1. เอาขึ้นเว็บด้วย GitHub Pages (ทำครั้งเดียว)

1. ล็อกอิน github.com แล้วกด **New repository**
2. ตั้งชื่อ เช่น `sakura` เลือก **Public** แล้วกด **Create repository**
3. ในหน้า repo ที่ว่างอยู่ กดลิงก์ **uploading an existing file**
4. แตกไฟล์ zip ก่อน แล้วลาก **ไฟล์และโฟลเดอร์ข้างใน** (`index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `OFL.txt`, โฟลเดอร์ `icons`) ไปวาง
   - อย่าลากโฟลเดอร์นอกสุดไปทั้งก้อน เพราะ `index.html` ต้องอยู่ชั้นนอกสุดของ repo
5. กด **Commit changes**
6. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch** เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
7. รอ 1–2 นาที จะได้ลิงก์ประมาณ `https://ชื่อผู้ใช้.github.io/sakura/`

ถ้าทำบนคอมไม่สะดวก ทำบนมือถือผ่านเบราว์เซอร์ก็ได้ (เปิด github.com แบบ Desktop site)

## 2. ติดตั้งลงมือถือ

**Android (Chrome)**
1. เปิดลิงก์ใน Chrome
2. กดปุ่ม **install app** มุมซ้ายบนของแอป หรือเมนู ⋮ → **Add to Home screen** → **Install**
3. ไอคอนดอกซากุระจะขึ้นบนหน้าจอโฮม

**iPhone (Safari)**
1. เปิดลิงก์ใน Safari
2. กดปุ่ม **Share** (สี่เหลี่ยมมีลูกศรชี้ขึ้น) → เลื่อนหา **Add to Home Screen** → กด **Add**
3. ไอคอนดอกซากุระจะขึ้นบนหน้าจอโฮม

เปิดจากไอคอนแล้ว แอปจะเต็มจอ ไม่มีแถบ URL และหลังจากเปิดครั้งแรกแล้วจะใช้ได้แม้ไม่มีเน็ต

## 3. ข้อควรรู้บนมือถือ

- **จอจะไม่ดับเองระหว่างจับเวลา** แอปขอให้จอเปิดค้างไว้ตอนนับเวลา (พอกด pause จอจะดับตามปกติ)
- **ถ้าล็อกจอหรือสลับไปแอปอื่น** เวลายังนับถูกต้อง แต่เสียงจะหยุด และเสียงกระดิ่งตอนหมดเวลาจะดังตอนกลับเข้าแอป
  (มือถือไม่ยอมให้เว็บแอปทำงานเบื้องหลัง) ถ้าต้องการให้เตือนตอนล็อกจอ ใช้นาฬิกาปลุกของมือถือคู่กัน
- **iPhone:** ถ้าเปิดโหมดเงียบ (สวิตช์ด้านข้าง) เสียงในแอปจะไม่ดัง
- **เสียงบรรยากาศ** เริ่มหลังจากแตะหน้าจอครั้งแรก ปรับ/ปิดได้ที่ปุ่มลำโพงมุมขวาบน

## 4. เวลาแก้แล้วอัปเดต

1. อัปไฟล์ใหม่ทับใน GitHub (Add file → Upload files)
2. ใน `sw.js` เปลี่ยน `sakura-pomodoro-v1` เป็น `v2`, `v3` ... ทุกครั้งที่อัปเดต
3. ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง ก็จะได้เวอร์ชันใหม่
